# AWS Support Plans Matrix Cheat Sheet

This table summarizes all the details tested on AWS Support Plans.

---

## Complete Comparison Matrix

| Feature | Basic (Free) | Developer | Business | Enterprise On-Ramp | Enterprise |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Pricing** | **Free** | Greater of **$29/mo** or 3% of usage | Greater of **$100/mo** or 10%–3% | Greater of **$5,500/mo** or 10% | Greater of **$15,000/mo** or 10%–3% |
| **Target Workload** | Experimentation, personal projects | Non-production, dev/test | Production workloads | Business-critical workloads | Mission-critical workloads |
| **Communication Channels** | Customer service web form (billing only) | **Email only** (during business hours) | **24/7 Phone, Chat, and Email** | **24/7 Phone, Chat, and Email** | **24/7 Phone, Chat, and Email** |
| **Authorized Contacts** | Any | **1 primary contact** | **Unlimited contacts** | **Unlimited contacts** | **Unlimited contacts** |
| **General Guidance SLA** | None | < 24 business hours | < 24 hours | < 24 hours | < 24 hours |
| **System Impaired SLA** | None | < 12 business hours | < 12 hours | < 12 hours | < 12 hours |
| **Production System Impaired SLA** | None | None | **< 4 hours** | **< 4 hours** | **< 4 hours** |
| **Production System Down SLA** | None | None | **< 1 hour** | **< 1 hour** | **< 1 hour** |
| **Business-Critical System Down SLA** | None | None | None | **< 30 minutes** | **< 15 minutes** |
| **AWS Trusted Advisor** | 7 core checks | 7 core checks | **Full checks (all 5 categories)** | **Full checks** | **Full checks** |
| **Technical Account Manager (TAM)** | None | None | None | **Pool of TAMs** | **Designated TAM** |
| **Support Concierge** | None | None | None | Available | **Designated Concierge** (Billing / account specialist) |
| **Infrastructure Event Management (IEM)** | None | None | Available for additional fee | **Included** | **Included** |
| **AWS Well-Architected Reviews** | Self-guided | Self-guided | Self-guided | AWS-assisted | **AWS-led reviews** |

## ⚡ 30-Second Exam Recall Tricks
1. **Want 24/7 phone or chat support?** Minimum plan is **Business**.
2. **Want a designated Technical Account Manager (TAM)?** Minimum plan is **Enterprise**.
3. **Want a pool of TAMs?** That's **Enterprise On-Ramp**.
4. **Production system is completely down (< 1h response)?** Minimum plan is **Business**.
5. **Business-critical system is down (< 15 min response)?** Only **Enterprise**.
6. **Full access to AWS Trusted Advisor recommendations?** Minimum plan is **Business**.
7. **Want an AWS Support Concierge for billing disputes?** **Enterprise** plan.
