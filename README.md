# AWS Certified Cloud Practitioner (CLF-C02) Master Study Suite

Welcome to your complete training repository for the **AWS Certified Cloud Practitioner (CLF-C02)** exam.

---

## 🎯 Exam Quick Facts
- **Exam Code:** CLF-C02
- **Duration:** 90 minutes
- **Number of Questions:** 65 (50 scored, 15 unscored beta questions)
- **Question Types:** Multiple choice (1 correct out of 4) and Multiple response (2 or more correct out of 5+)
- **Passing Score:** 700 / 1000 (Scaled score ranging from 100 to 1000)
- **Cost:** $100 USD (Includes a 50% discount voucher for your next AWS exam upon passing)
- **Delivery Method:** Pearson VUE testing center or online proctored exam

## 💻 Interactive Web Application

An interactive web app is ready in your workspace!

### How to Launch the Web App
1. **Quick Launch (Windows):** Double-click `start-study-app.bat` in the workspace root.
2. **Or via Terminal:**
   ```bash
   cd "web-app"
   python server.py
   ```
   *Your browser will automatically open to `http://localhost:8000`.*

### Web App Features
- **Interactive Practice Exam Simulator:** 65 questions, 90-minute timed countdown, question navigator grid, flag for review, instant feedback mode, and scaled score calculation (100–1000) with domain breakdown.
- **High-Yield 3D Flashcards:** 52 keyword trigger cards ("If you see X, think Y") with flip animation, spaced repetition mastery tracking, and category filtering.
- **Domain Study Guides Reader:** In-depth interactive lessons for Domains 1–4, 6 Cloud Advantages, Well-Architected Framework, CAF, and Shared Responsibility Model.
- **Interactive Comparison Cheat Sheets:** Side-by-side matrices with live text search for Storage, Databases, Security Tools, and Support Plans.
- **Global Search (Ctrl+K):** Instant search across questions, flashcards, and cheat sheets.
- **Dark / Light Theme:** Seamless toggle with local storage persistence.

## 🗓️ Study Plans

### Option A: The 2-Week Intensive Plan (1.5 - 2 Hours / Day)
- **Days 1–3:** Complete Domain 1 (Cloud Concepts & Well-Architected Framework).
- **Days 4–7:** Complete Domain 2 (Security, IAM, Compliance, Shared Responsibility).
- **Days 8–11:** Complete Domain 3 (Core Services: Compute, Storage, DB, Network, Monitoring).
- **Day 12:** Complete Domain 4 (Billing, Pricing, Support Plans).
- **Day 13:** Review all Cheat Sheets & Flashcards.
- **Day 14:** Take Full Practice Exam 01, review wrong answers, and take the exam!

### Option B: The 4-Week Comprehensive Plan (45–60 Mins / Day)
- **Week 1:** Cloud Concepts (CAF + Well-Architected Framework) & AWS Global Infrastructure.
- **Week 2:** Security, IAM, Encryption, and Compliance Tools.
- **Week 3:** Core Services (Compute, Storage, Networking, Databases).
- **Week 4:** Billing, Support, Cost Management, Cheat Sheets & Practice Exams.
