AWS Well-Architected Framework Alignment

Comprehensive reference matrices for Multi-AZ disaster recovery, least-privilege IAM policies, and VPC subnet allocation standards.

Security Pillar (Zero-Trust VPC)
• Subnet Segregation: Databases reside strictly in isolated private subnets with no route table entry to Internet Gateways.
• Egress Filtering: Compute instances reach external APIs through managed NAT Gateways with Elastic IPs.
• AWS PrivateLink: Traffic to S3, DynamoDB, and Secrets Manager stays on the private AWS network backbone, bypassing NAT bandwidth costs.
• KMS Envelope Encryption: Customer Managed Keys (CMKs) with annual automated key rotation encrypt all EBS volumes, RDS storage, and S3 buckets.
Reliability Pillar (Multi-AZ Resilience)
• Aurora Multi-AZ: 6-way storage replication across 3 AZs. If the primary writer fails, an automated DNS failover promotes a read replica in under 30 seconds.
• Auto Scaling Target Tracking: ECS Fargate services scale out when average CPU exceeds 65% or ALB request count surges.
• Dead-Letter Queues (DLQ): Poison pill messages are isolated after 3 processing retries to prevent blocking upstream worker queues.
• Route 53 DNS Failover: Automated health checks trigger cross-region failover if the primary region's ALB becomes unreachable.
Performance Efficiency
• Sub-Millisecond In-Memory Caching: ElastiCache Redis cluster caches frequent database query results and user sessions.
• CloudFront Edge Offloading: Caches static SPA assets and terminates TLS 1.3 at 450+ global Points of Presence.
• Read Replicas: Read-heavy queries are directed to asynchronous read replicas to protect primary writer CPU.
Cost Optimization
• S3 Lifecycle Policies: Transitions aging objects from Standard to Infrequent Access (IA) at 30 days and Glacier Flexible Archive at 90 days.
• Fargate Serverless Compute: Eliminates idle EC2 instance overhead; billed strictly per second of vCPU and memory allocated.
• VPC Gateway Endpoints: Provides free private routing to Amazon S3 and DynamoDB without incurring NAT data processing charges.
